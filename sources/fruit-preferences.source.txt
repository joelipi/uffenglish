//   step video slugs:   {course}-{askId|ansId}-{step:02}

//   UGC clips:          {recorder}-{inviter}-{course}-{lesson}-{step:02}  (share
//                       codes; recorder first, the code that invited them second —
//                       the same code twice when self-initiated, e.g. the first
//                       ask lesson). No "response" marker: the step number is
//                       already unique within the lesson.
//   overlay HTML:       rungs template; take N shows rungs 1..N-1 plain,
//                       rung N filled + bold (the spoken line), rest blank
//   SRT / cue arrays:   from the phrases in order (timings measured at render)
//   routing:            each pair's topics run question -> branch -> answers; the
//                       branch's k-th choice targets the k-th answer group; each
//                       answer advances past its group (1-4 choices supported)
//   republish:          the answer lesson replays each topic's question video with
//                       publishLessonId = the ask lesson id
//   lesson framing:     every lesson opens straight on content (no intro step);
//                       recap settings + success step are code-owned per the
//                       friend-lesson rules (recap = UGC only; overlay shareCta);
//                       the chain's LAST answer lesson closes with a code-owned
//                       goodbye block instead of the record phase (there is no
//                       next question set to record)
//   response type:      every content step is friendClosedResponse; the branch step
//                       is the one with choices
// Within a pair, a topic is written in order: question variants, friend clip +
// branch labels, then the answer variants — so each topic is self-contained.
// Media (background, mirror, effect, character, sounds, ...) is pipeline-only:
// reserved slots, never emitted to the app config. Omitted here until used.
//

// two fruits, as if you're hosting a guest with two kinds of fruit in the fridge
// and offering them. Countable fruits take "a/an"; non-countable ones
// (pineapple, grapes, watermelon, cantaloupe, berries) take "some" or a
// portion word ("a slice of", "a bit of"). All vocabulary is reusable in real life.
// ===========================================================================
